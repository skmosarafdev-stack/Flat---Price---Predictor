🏠 Flat Price Predictor

A machine learning–powered web application that estimates residential flat prices using important property characteristics. The system provides quick price predictions through a simple, responsive, and user-friendly interface.

🚀 Live Application

🌐 Live Website:
https://flat-price-predictor-zfkq.onrender.com

---

📌 About the Project

Flat Price Predictor is a full-stack Machine Learning application developed to estimate the expected price of a flat from user-provided property information.

Users can enter details for a single flat or multiple properties, and the trained ML model generates an estimated price in Lakhs.

✨ Key Features

- 🏠 Predict prices for multiple flats
- 📊 Instant ML-based price estimation
- 📝 Maintain prediction history
- 🗑️ Remove individual prediction records
- 🧹 Clear the complete prediction history
- 🔄 Start a fresh prediction session
- 📱 Responsive interface for different screen sizes
- 🔌 Backend API for handling predictions
- 🤖 Integrated Machine Learning model
- 🎨 Modern and interactive user interface

---

🧠 Machine Learning Model

The prediction system is based on Multiple Linear Regression.

The model learns the relationship between different property attributes and their corresponding prices to generate an estimated market value.

Input Parameters

Feature| Description
Area| Property size in square feet
Facing Direction| Direction the flat faces
Floor Number| Floor on which the flat is located
Car Parking Size| Parking area in square feet
Bedrooms| Number of bedrooms

🎯 Prediction Output

The model predicts the estimated Flat Price in Lakhs.

---

🧭 Facing Direction Encoding

To process the categorical facing-direction feature, the application converts each direction into a numerical value:

Direction| Encoded Value
East| 1
West| 2
South| 3
North| 4

The trained model was evaluated using several standard regression metrics:

- R² Score
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- Mean Absolute Error (MAE)

Evaluation Results

Metric| Result
R² Score| 0.9985
MSE| 0.4696
RMSE| 0.6853 Lakhs
MAE| 0.5541 Lakhs

These metrics indicate that the trained model performs strongly on the available evaluation data.
